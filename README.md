

# Smart Expense Tracker API

## Install
```bash
python -m pip install -r requirements.txt
```

## Run
```bash
python -m uvicorn src.main:app --reload
```

Open:
http://127.0.0.1:8000/docs

## Run Tests
```bash
pytest
```
